# Quickstart

[`quickstart.ipynb`](quickstart.ipynb) walks through the `weirdchat` client library: browsing the dataset's behaviors, rubrics, and prompt patterns; inspecting a pattern's prompts and judged transcripts; and reproducing a behavior by resampling responses from OpenRouter and grading them with the dataset's reference rubric judge.

To run the notebook yourself, install dependencies with `uv sync`, and set the `OPENROUTER_API_KEY` environment variable with your OpenRouter API key.
